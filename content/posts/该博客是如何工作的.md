- 他是架设在github上的，并由Obsidian管理。
- 网页模板使用的是 <https://github.com/jackyzha0/quartz> 的笔记模板，特点之一是双链以及关键字的快速搜索。

# 工作原理是什么？
1. 笔记在本地完成。
2. 当笔记被Obsidian 的 Github Publisher 插件上传到github项目内，笔记被Action编译并发布。

# 如何配置这样的网站？
1. 复制模板
2. 设置github相关密钥并导入Obsidian 的 Github Publisher 插件
3. 设置 Github Publisher 插件的配置
4. 在Obsidian中写笔记并保存上传
